Shine & Sing - Group 13 - Ed submission

Upload the contents of this folder to the Assignment 2 workspace on Ed.
shine_sing.qpf, rtl/, tb/, assets/ and run_ed.sh should be at the workspace root.

Run the checks with the course version of Verilator (5.050):
  python3 -m pip install -r requirements.txt
  python3 tools/check_project.py --require-trained
  python3 tools/test_recordings.py
  python3 tools/test_saved_templates.py
  python3 tools/test_image_assets.py
  sh run_ed.sh

Run selected RTL tests by adding their names:
  sh run_ed.sh tb_recording_classifier tb_system tb_video_source
Run the deliberate-fault tests with:
  python3 tools/test_course_mutations.py
Logs and simulation builds are written to build/.

Quartus: open shine_sing.qpf in Quartus Prime Lite 18.1 and compile it.
Or run: quartus_sh --flow compile shine_sing
No SOF or fitted database is included. Use the newly compiled SOF for the board.

The default classifier uses the group WAV recordings in data/recordings/.
To retrain, use:
  python3 tools/train_recordings.py --samples data/recordings --sim verilator
Then rerun the tests and compile Quartus again.
For SignalTap captures, use:
  python3 tools/train_saved_templates.py ee.csv ah.csv oo.csv aw.csv
Saved training results are in rtl/templates_training.json. Training accuracy
is not the same as accuracy on new recordings or the board microphone.

To replace an image:
  python3 tools/import_image.py photograph.png --slot 2
To run the video simulation and render its output:
  python3 tools/run_demo.py --sim verilator
Generated demo pictures go to docs/evidence/, which is not part of this branch.
These pictures use synthetic audio events, not live microphone input.

rtl/ and quartus/ contain the hardware and required vendor IP.
tb/ contains the tests and tb/fixtures/ contains their small input files.
assets/ contains memory data, image previews and expected test results.
assets/h95/ is a separate classifier test fixture, not the default templates.
tools/ contains test, training, image-conversion and reference scripts.
SOURCE_CREDITS.txt identifies the reused course code. Original reference
copies, old reports and saved demo pictures are retained on main only.

The report, required AI Statement and full session exports are separate
Canvas submissions; they are not included in this Ed code folder.
